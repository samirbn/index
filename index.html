شاشات تفاعلية بتصميم داكن وأنيق

صُممت واجهات SilaSoft POS بعناية فائقة لتوفير سرعة متناهية للتاجر مع وضوح عالي ومريح للعين أثناء العمل اليومي.

الرئيسية ولوحة التحكم

متابعة مبيعات اليوم، نواتج المخزون، ورسم بياني تفاعلي للأداء الأسبوعي.

إدارة المنتجات والمخزون المنفصلة

تحكم منفصل بالأصناف، استيراد Excel، طباعة الباركود، وإحصائيات المخزن.

أرشيف فواتير المشتريات والديون

سجل كامل لفواتير الموردين، متابعة المتبقي والمدفوع، ومعاينة تفاصيل الفاتورة.

مواصفات وإمكانيات SilaSoft POS

مصمم بأسلوب هندسي متطور يلبي الاحتياجات الواقعية للتجارة الجزائرية

💰

هيكلة الأسعار المتعددة (Multi-Pricing)

دعم 4 فئات تسعير منفصلة: **قطاعي (تجزئة)**، **جملة**، **موزع**، و**عروض خاصة**، مع التحديث الآلي الفوري لجميع أصناف السلة بنقرة زر واحدة.

📦

منطق الكرتون وتعبئة الوحدات (Carton Logic)

إمكانية بيع، شراء، وإرجاع المنتجات بالكرتون أو العلبة أو القطعة، مع التحويل الدقيق والآلي للكميات داخل المخزن.

🖨️

محرك الطباعة والفواتير والمفضلات السريعة

طباعة الفواتير الحرارية 80mm ورسمية A4/A5، طباعة ملصقات الباركود المخصصة، وإضافة 5 مجموعات مفضلة للبيع السريع باللمس.

📊

تحليل الأرباح وحاسبة الزكاة

حساب صافي الأرباح الحقيقية بدقة، إدارة الديون والكريدي، تسجيل المصاريف الهالكة واليومية، مع حاسبة زكاة عروض التجارة وفق الأسس الشرعية.

🌐

ربط أجهزة الشبكة والـ Mobile Server

تشغيل النظام كخادم رئيسي أو أجهزة فرعية على شبكة محلية (Réseau Local)، مع خادم Mobile REST API المدمج والمحمي بصمت.

🛡️

الأمان والنسخ الاحتياطي التلقائي

معاملات قواعد بيانات بنظام ACID للحماية من فقدان البيانات، نسخ احتياطي واسترجاع بضغطة زر، وتحديد صلاحيات المستخدمين (المدير والبيع).
